# DIKWP Mesh92 K–12 Future-Ready Education OS

Created by Yucong Duan (段玉聪).

Version 1.0.0 · 2026-08-24 · Author: Yucong Duan / 段玉聪 · Apache-2.0

This offline-first system retrofits existing K–12 subjects for an AI-disrupted labour market. It covers 12 grades, 8 reversible support profiles, 4 overlays, 96 grade-profile plans, 48 projects, 4 competing future-of-work models, an evidence-based Learning Passport, and a Mesh92 pilot ledger.

Open `index.html` in a modern browser. No server, account, model API, database, or network is required.

Optional CLI:

```bash
python tools/generate_plan.py --grade 7 --profile P4 --overlay O1 --out outputs/demo.json
```

The system must not be used for automated admissions, tracking, psychological assessment, discipline, ability classification, career decisions, covert profiling, or ranking. Primary-school students must not independently use open-ended generative content features. All high-impact uses require human review and lawful governance.
